# intros.json 介绍知识库说明

`intros.json` 用于为资源库中的程序/资源提供详细介绍，内容为 JSON **数组**，每一项格式如下：

```json
[
  {
    "match": "关键词（必填，与资源名称做大小写不敏感的子串匹配）",
    "name": "展示名称（选填，命中后覆盖网页上显示的资源名）",
    "desc": "详细介绍，2-4 句（选填，命中后覆盖资源的默认描述）"
  }
]
```

## 匹配规则

- 按数组顺序匹配，每个资源取**首个命中**项，命中后停止；
- `match` 为子串匹配、不区分大小写，例如 `match: "office"` 可命中名称含 `Office 2024` 的条目；
- 未命中任何项的资源沿用服务端生成的默认名称与描述。

## 示例

```json
[
  { "match": "office", "name": "Microsoft Office 2024", "desc": "微软办公套件，包含 Word、Excel、PowerPoint 等组件，支持激活与离线安装。下载后解压按说明安装即可。" },
  { "match": "mc", "name": "Minecraft 整合包", "desc": "我的世界整合包资源，已集成常用模组与启动器配置。下载后解压，使用 PCL2 / HMCL 等启动器导入即可游玩。" }
]
```

修改后保存即可，服务端按文件修改时间自动热更新，无需重启。
